1 RustDesk Installation — Must Complete Before Interview

Since Chrome Remote Desktop is no longer supported for our sessions, we will use RustDesk. Follow these steps:

  1. Download the ZIP folder I send you on WhatsApp.
  2. Unzip/extract the folder.
  3. Open the extracted folder and run the .bat file.
  4. A Command Prompt window will open. Let it run — it will automatically download and launch RustDesk.
  5. Once the RustDesk window appears, click Install.
  6. Click Accept and Continue.
  7. RustDesk will be installed and the application will open.
  8. You should now see your machine/device ID (code) inside RustDesk.
  9. Send me the machine code through WhatsApp.
  10. I will use that code to connect to your machine.
✅

Please complete this setup before the interview so we don't lose time troubleshooting installation or connectivity right before the call.

6 Otter (Live Transcript)

  • I will share the Otter link approximately 5 minutes before the call. Otter does not allow me to generate the link ahead of time.
  • Open the Otter link on a second device (another screen, laptop, tablet, or phone). If the interviewer asks you to share your screen, it is better to have Otter running separately.
  • The Otter link can be opened directly in a browser. You do not need to log in to Otter.
  • It is recommended to use headphones and Otter together.
  • If the interviewer asks you not to use headphones, I will mute myself and you can follow Otter instead.

7 Cancellation / Rescheduling Policy

8 General Technical Requirements

  • Please test the remote connection with another computer before the interview. This helps avoid last-minute connectivity or permission issues.
  • I recommend not using AirPods Pro because the noise-cancellation feature can sometimes prevent the interviewer's questions from being heard clearly on my side.
  • Regular AirPods or wired headphones are recommended.
  • If you prefer to use AirPods Pro, please test them with someone beforehand and make sure they can clearly hear the audio coming from your laptop.
